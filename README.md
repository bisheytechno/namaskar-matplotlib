## How to Run

**1. Clone:**
```bash
git clone https://github.com/bisheytechno/namaskar-matplotlib.git
cd namaskar-matplotlib
```

**2. Virtual Environment:**
```bash
python -m venv myvenv
myvenv\Scripts\activate
```

**3. Install:**
```bash
pip install -r requirements.txt
```

**4. Run:**
```bash
jupyter lab
```
